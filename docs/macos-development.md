# Apple Silicon macOS 移植（开发中）

本分支基于上游 `189b8d54`，目标是原生 ARM64 云游戏，不使用 Docker、虚拟机或 Rosetta。当前仍是开发版，不能视为全部任务已经验证。

## 构建

在 macOS 14 或更新版本的 Apple Silicon 上，使用原生 Python 3.12 环境安装项目依赖和 PyInstaller 6.22.3，再运行：

```sh
MARCH7TH_BUILD_PYTHON=/path/to/venv/bin/python sh tools/build_macos.sh --dmg
```

脚本先下载 RapidOCR 3.8.1 所需的三个 PP-OCRv4 模型，并核验其上游 SHA-256。默认在 `/private/tmp/march7thassistant-build-<uid>/dist/` 生成 `.app` 和 `.dmg`；可用 `MARCH7TH_BUILD_ROOT` 指定构建目录。构建使用临时目录，避免某些文件提供程序附加的 Finder 信息阻碍签名。App 使用临时的 ad-hoc 签名，**没有 Apple Developer ID 签名或公证**。首次打开可能受 Gatekeeper 限制；不要关闭系统安全保护。正式发布前应使用有效证书签名和公证。

当前打包默认采用 ONNX Runtime CPU，也提供 OpenVINO CPU 和失败回退。macOS 使用 OpenVINO 2025.3.0 与 NumPy 2.2.6：上游 2026.2.0 包中部分动态库无法由当前 Apple 工具链重写。打包时省去 TBB 可选绑定和分配器辅助库；测试包中的两种后端均通过离线合成样本识别。OpenVINO 在真实游戏画面上的识别和坐标仍需验证；受限执行环境中自检未能初始化并回退到 ONNX；正常 macOS 环境中合成样本自检通过。

## 数据与隐私

配置和浏览器资料放在 `~/Library/Application Support/March7thAssistant/`，日志放在 `~/Library/Logs/March7thAssistant/`。程序资源从 App 读取。浏览器采用独立资料目录，macOS 不导出明文 Cookie，也不将扫码内容写入日志或发送到第三方通知渠道。 错误发生时不会自动保存或转发画面，避免登录二维码被误记录；可通过应用内预览查看当前画面。设置页可导入上游或 Docker 配置中的非敏感任务设置，导入前会备份当前配置；不会导入账号、通知凭据、任意命令或 Windows 路径，也不会修改原目录。

登录资料不能从 Docker Chromium 可靠迁移，需要重新扫码。浏览器优先使用已配置的来源；内置 Chrome for Testing 由 Selenium Manager 获取，macOS 默认使用官方来源，并验证 ARM64 和驱动主版本。应用不携带 Chrome 本体，首次安装浏览器需要网络。

## 使用边界

首次配置默认启用云游戏、无头浏览器和本地二维码登录。任务日志页显示当前任务的登录二维码，以及生成、扫码、手机确认、验证、成功和超时状态；不会显示先前任务遗留的二维码。画面预览使用独立的本机浏览器调试连接按需采集，不依赖任务的截图时机；可选择每 10 秒请求一次。连接异常时按有限频率重试，任务结束后清理本地预览。 预览通过连续低频样本提示画面持续较暗或长时间未变化；提示不能区分正常加载、静态界面和真实视频故障，不会自动中断任务。Mac 睡眠或应用关闭期间不会执行任务。唤醒或下次启动应用时会根据调度检查点记录最近七天内错过的计划，可选择补跑最近一项；已有任务运行时等待空闲，不打断当前任务。时间回退时暂缓调度以避免重复。应用退出后没有常驻代理，定时任务不会在关闭期间运行。

登录时启动是可选功能，由当前用户的 LaunchAgent 在登录时启动 App；关闭开关仅移除本应用的代理文件，不终止当前运行实例。用户退出登录后任务不会继续运行。系统通知依赖 macOS 授权。 日志页的运行诊断每 5 秒采样任务进程及其子进程，显示 CPU、内存、浏览器、OCR 和最近采集/识别时间；每分钟记录一次有限大小的本地诊断日志。若系统不允许枚举子进程，会明确标注仅统计任务进程。诊断不记录画面或识别文字。

上游锄大地和传统模拟宇宙工具明确依赖 Windows，当前在 macOS 中不可运行；单项启动时会说明原因，完整运行时会记录跳过。设置界面也标明了限制。差分宇宙与其他任务是否能实际完成，仍需真实游戏逐项验证。进程正常结束不代表每个上游步骤已经成功，界面提示查看日志。

## 当前验证与未验证项

已验证：原生 ARM64 Chrome for Testing 及匹配驱动启动；无头页面 DOM 与截图变化；浏览器 `chrome://gpu` 报告硬件合成和视频解码可用；云游戏官网登录 iframe 与二维码可以生成；本地二维码文件权限为 `0600`；ARM64 ONNX OCR 在中英文合成样本中返回文本和坐标；测试包中的离线 OCR 自检通过；指定范围的单元和组件测试通过。隔离的 ARM64 无头浏览器测试验证了 0.5、1.0、1.5、2.0 浏览器缩放下的截图裁剪与点击坐标，以及按住移动、大小写按键、中英文文本输入和指针锁定禁用；其中 1.5 倍缩放还经过项目实际云截图接口。无头模式省去按键前重复鼠标聚焦：本机隔离测试约从 32 秒降到 12 秒；这不是实际游戏性能结果。上述浏览器与 OCR 测试并非真实游戏任务测试。 任务进度按初始化、登录、排队、加载、识别和执行阶段显示；完整运行的三步进度表示启动、配置任务和奖励领取的顺序，不代表各上游任务已全部验证。运行诊断组件及其隐私限制通过隔离测试；完整窗口在 Qt 离屏模式下因 macOS 原生窗口依赖而崩溃，不能以此替代桌面验证。

尚未验证：用户扫码及登录持久化、云游戏排队和真实视频帧、坐标与输入、各实际任务完成情况、App 界面完整交互、系统通知、真实睡眠/唤醒和登录启动、Finder 安装、Gatekeeper、完整的资源占用与 Docker 对比、OpenVINO 在真实游戏画面上的准确率和不同 macOS 版本兼容性。不要把这些项目标记为已完成。

差分宇宙和货币战争的中途接管会连接小助手已有的云游戏浏览器，并检查播放器是否存在；没有会话、调试端口无法确认或连接失败时会终止，不会新建游戏会话冒充接管。隔离浏览器的合成页面验证了连接和缺少播放器时的安全断开，真实游戏中的接管与任务完成仍需验证。

浏览器控制连接异常时，退出流程会继续关闭控制进程并清理属于小助手的数据目录的浏览器；macOS 上重启前会限时等待进程退出，必要时结束未退出的进程，失败则记录错误。此路径通过模拟故障和隔离浏览器测试；尚未覆盖真实云游戏断线后的恢复。

忘却之庭、虚构叙事和末日幻影的流程会区分已满星、关卡识别失败、战斗失败和奖励领取失败。完成时间只在已确认满星或本轮领取奖励后记录，领取循环有次数上限；失败会向完整运行传递。相关逻辑通过隔离测试，实际关卡识别、战斗和奖励领取仍需在游戏中验证。

每日实训启用奖励领取时，会进入实训页面检查 500 活跃度标记，即使菜单中没有奖励提示；无法确认时不会记录当日完成时间。用户关闭奖励领取时，按已识别的任务或活跃度状态完成日常，不强制开启领取。领取循环和关闭提示均有失败处理，相关判断已做隔离测试，实际游戏页面仍需验证。

定时任务在当前任务暂停时到点，会按补跑设置记录跳过或等到空闲后补跑；没有历史调度记录时，首次启动会检查当前分钟的计划。调度状态写入失败会在日志提示，避免静默丢失恢复信息。测试覆盖模拟时钟、暂停与 Qt 事件循环，不能替代真实 Mac 睡眠、唤醒和重启测试。

首页手动打开云游戏时，如果已有任务进程正在运行，会阻止新浏览器切换干扰该任务；浏览器打开后提示用户登录并进入游戏，不将浏览器启动视为游戏已加载。新构建的 App 中，Selenium Manager 0.4.44 的 ARM64 可执行文件通过离线自检；该自检不下载浏览器，不能证明干净环境下的网络安装成功。

2026-10-30 在本机使用独立空数据目录，运行打包 App 的首次安装自检，成功下载 Chrome for Testing 140.0.7339.207 及匹配驱动，二者通过 ARM64 和版本校验。随后使用该目录中的浏览器通过本地合成页面的输入、截图和独立预览自检；这是一次当前网络环境下的测试，不代表所有网络环境均可下载，也未验证游戏登录。

macOS 云游戏错误日志不记录 Selenium 异常原文、登录异常堆栈、浏览器启动参数、镜像地址或视频截图返回的页面调试内容；保留操作阶段和异常类型辅助排查。使用模拟敏感内容测试过登录与截图错误分支，这不是对所有第三方依赖日志的完整隐私审计。

在 macOS 上，若 Selenium 明确报告无头浏览器会话创建失败，会先清理失败的进程，再尝试一次有窗口浏览器；临时切换复用同一浏览器资料目录，不会修改全局无头设置。配置错误、登录失败及其他异常不会触发该回退。隔离测试覆盖了分类、清理失败和回退后登录模式；真实游戏及真实窗口回退仍需验证，任务级兼容性也尚未全部验证。

预览请求若没有采集进程响应，30 秒后会显示超时；自动刷新不会覆盖尚在处理的请求，旧画面也不会被当作新请求的结果。该行为经过 Qt 组件和隔离采集测试，真实云游戏画面仍需验证。

预览响应将请求标识和图像一起原子写入本地私有文件；界面只接收当前请求对应的图像，防止旧请求在新请求发出后才完成时造成误显示。该竞态已用可控并发测试覆盖，并通过隔离浏览器的连续画面测试。

macOS 浏览器使用系统显示缩放，并在打开有窗口模式时根据当前显示器可用空间缩放画面；旧配置中的浏览器 DPI 百分比在 macOS 上不再生效。游戏逻辑尺寸保持 1920×1080，鼠标输入按显示比例换算。已在本机有窗口及无窗口的隔离浏览器中验证截图尺寸和目标点击，尚需在真实云游戏中验证完整画面与任务运行。改变显示器或系统缩放后，可重新打开游戏窗口以重新计算适配尺寸。

首页先打开云游戏后，启动云游戏任务时会释放首页的浏览器控制连接，由任务进程接管。任务结束或启动失败后会清理可能残留的本应用浏览器。隔离 Chrome 测试验证了控制进程退出后页面状态仍可由新控制进程读取；真实游戏会话和登录状态的移交仍需验证。

如果首页控制进程无法释放，应用会保留该连接并中止新任务，避免两个控制进程同时操作；这一失败分支已通过隔离测试。

首页菜单和卡片编辑器会标注 macOS 不支持的 Windows 工具；旧工具的目录和重置操作会提示原因，不再调用 Windows 专用接口。云游戏开关在 macOS 上显示为固定模式；若外部环境变量关闭云游戏，界面会说明原因。相关配置、卡片和多语言目录一致性测试已通过；新增文案的各语言翻译仍可能回退到中文。

2026-10-30 对云游戏、macOS 兼容、OCR、预览、日常及调度等相关测试进行组合回归，结果为 272 项通过、21 项跳过。包含本地隔离浏览器的二维码模拟、控制交接、预览和多缩放输入测试；并非整个仓库的测试，也不代表真实游戏任务通过。

清体力副本的失败重试有上限，重试未成功或无法进入下一轮时不会记为成功；体力计划出错会保留未完成和后续计划，并向上报告失败。每次识别到一轮战斗胜利后即记录该轮次数，后续失败时只保留未确认部分。该计数依赖战斗结果识别，实际游戏画面中的准确性仍需验证。

非保留模式下，每轮完成后会立即写入剩余计划；写入失败时停止继续战斗。格式错误或次数无效的计划项会保留并跳过。模拟中断测试验证了已保存的剩余次数，尚未验证真实游戏中断或意外断电。

使用实际配置文件的独立进程测试中，写入已确认进度后立即终止进程，重新读取仍能得到正确的剩余计划；配置只读时会在执行前停止。该测试不能代表硬件断电后的文件系统行为。

检测到邮件、支援或成就奖励提示后，如果领取按钮或必需的确认操作未能识别，会记录未确认并使 macOS 完整运行报告失败；未启用的奖励仍按设置跳过。其他奖励类型的实际页面和结果仍需游戏内验证。

### 合成 OCR 性能基准

在 Apple Silicon、10 个逻辑 CPU 的本机环境下，使用生成的中文文本分别测试 1920×1080 全图及 700×180 裁剪图，各重复 8 次。两个后端均识别出预期文字，重复框坐标稳定，裁剪框还原到全图坐标后与全图识别的框起点最多相差 8 像素。该差异反映检测器对不同输入区域的结果，不能用来证明真实游戏的点击精度。

| 后端 | 初始化 | 全图识别中位数 | 裁剪识别中位数 | 进程 CPU 时间 | 采样内存峰值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ONNX Runtime CPU | 0.747 秒 | 0.357 秒 | 0.367 秒 | 20.842 秒 | 782.7 MiB |
| OpenVINO CPU | 0.888 秒 | 0.310 秒 | 0.496 秒 | 19.278 秒 | 845.3 MiB |

CPU 时间涵盖初始化与 16 次识别，是各 CPU 核心时间之和，不是墙钟耗时；内存仅在识别之间采样，不保证捕获瞬时峰值。单次运行会受系统负载影响，不能据此推断完整任务速度或内存泄漏，也不能替代 Docker 对比。完整测量见 [ONNX JSON](benchmarks/ocr-synthetic-onnx.json) 和 [OpenVINO JSON](benchmarks/ocr-synthetic-openvino.json)。

每个 OCR 模型会建立独立运行时会话；macOS 下将 ONNX 会话和 OpenVINO 推理线程各限制为最多 4 个，并将 ONNX 跨算子线程设为 1。初步对照中，默认、2 线程和 4 线程配置均能识别该样本；2 线程的 ONNX 全图中位耗时从约 0.35 秒升至 0.47 秒，因此选择 4 线程作为当前折中。实际游戏与更长时间运行仍需继续验证。

在安装了项目依赖和离线模型的源码目录中复测（分别在独立进程运行）：

```sh
python tools/benchmark_macos_ocr.py --engine onnx_cpu --iterations 8
python tools/benchmark_macos_ocr.py --engine openvino_cpu --iterations 8
```

脚本使用临时数据目录和合成图片，不读取游戏账户或截图；标准输出为 JSON，日志输出到标准错误。
